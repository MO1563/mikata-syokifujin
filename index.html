◆三方初期布陣

集結 タブ
集結の色（集結ごとに変更可）
名前入力（5名 / コマ＝頭文字）
※1番目の欄に入力した人のコマは、外郭が赤枠で強調されます
メモ（グレーのマスに配置）
※メモは配置不可（グレー）のマスに置けます。同じマスを再クリックで削除されます
GitHub 用データ
操作手順
1. 集結①〜⑳のタブを選択
2. 集結の色を選択（スウォッチでもOK）
3. 名前欄をクリックして「選択中」にする
4. ひし形の白マスをクリックで1名ずつ配置
5. 配置済みマスを再クリックで解除
6. 選択中の人が他マスに居れば移動します
7. メモ欄をクリックして文言を入力し、グレーのマスをクリックで配置
8. 左上の赤い矢印はクリックで左右の向きを切替
9. 「書き出す」でJSONファイルを保存し、そのファイルをGitHubにアップ
10. 別のPC／端末では、GitHubから落としたJSONを「読み込む」で反映
